# Куди піти? Where to go?

Цей веб-додаток створений на базі Django. Він дозволяє зберігати власні улюблені місця (кафе, парки, книгарні тощо) та за допомогою рандомайзера допомагає користувачам обрати, куди піти сьогодні. Дані користувача зберігаються локально за допомогою сесій.

**Як запустити проєкт локально:**

* Клонуйте репозиторій: ```git clone https://github.com/kttrryn/Where-to-go```
* Перейдіть у папку: ```cd where_to_go```
* Створіть та активуйте віртуальне середовище:
```python -m venv .venv```, потім 
для Mac/Linux ```source .venv/bin/activate``` 
для Windows ```.venv\Scripts\activate``` 
* Встановіть залежності: ```pip install -r requirements.txt```
* Застосуйте міграції: ```python manage.py migrate```
* Запустіть сервер: ```python manage.py runserver```
* Відкрийте сайт у браузері: http://127.0.0.1:8000/
